# Contributing

Thank you for helping to improve this list. Please read these rules before opening a pull request or an issue.
Submissions that do not follow them will be closed without review.

## No AI agent submissions

Pull requests and issues created by AI agents are **not accepted**. This includes submissions opened automatically
by bots or agents and AI-generated submissions sent on someone's behalf. They will be closed without review.

## What is accepted

Only two kinds of links are accepted:

1. **Official takeout pages.** A link to the data export (takeout) page or help article of the service itself,
   hosted on the service's own domain. For example, `https://takeout.google.com` for Google.
2. **Free and open source tools.** A tool that helps to export, convert or back up your own data. It must have
   a public source code repository and an [OSI-approved license](https://opensource.org/licenses),
   and it must be fully usable for free.

## What is not accepted

* Commercial services and tools: paid, freemium, open core, SaaS, trial-based, "export as a service", etc.
* Third-party websites, blog posts or guides about how to export data from a service. Link to the official page instead.
* Affiliate, referral or tracking links.
* Pull requests and issues created by AI agents.

## Format

* Add the link to the most relevant section and keep the existing format:
  `* [Name](https://link) - short description`
* One service or tool per line, no duplicates.
